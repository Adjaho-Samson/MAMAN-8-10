## 🚀 **Utilisation**

### **1️⃣ Installation**

1. Ouvre le dossier dans VS Code
2. Utilise **Live Server** ou ouvre `index.html`

### **2️⃣ Ajoute les Photos**

```
assets/images/
├── maman/
│   └── hero.jpg           (photo du haut)
├── famille/
│   └── famille.jpg        (photo de famille finale)
└── souvenirs/
    ├── photo-01.jpg       (2x2)
    ├── photo-02.jpg
    ├── photo-03.jpg
    ├── photo-04.jpg       (2x1)
    ├── photo-05.jpg
    └── photo-06.jpg       (2x2)
```

### **3️⃣ Ajoute la Musique**

- Ajoute `assets/audio/birthday.mp3`

### **4️⃣ Personnalise le Texte**

Édite directement dans `index.html`.

## 🎨 **Personnalisation**

### **Couleurs**

Modifie dans `css/style.css` :

```css
:root {
  --gold: #b18a52; /* Couleur principale */
  --rose: #c8a7a0; /* Couleur secondaire */
  --cream: #f8f4ed; /* Fond clair */
}
```

### **Animations**

Tous les effets sont optimisés dans :

- `css/animations.css`
- `js/animations.js`
